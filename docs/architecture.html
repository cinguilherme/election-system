Node Deep-Dive: :precinct Entity Actor (Batch & Dedup Core)

Compression Core

Architecture & Memory Mechanics

Each precinct actor runs as a single-threaded entity actor in Clojure. It retains an in-memory :voted-ids set to reject duplicate votes in O(1) time without DB lookups. Incoming ballots are accumulated in :pending-ballots.

BATCH_SIZE: 200
TICK_MIN_BATCH: 200
TICK_MAX_AGE_MS: 10000 (staleness bound)

Database Write Impact

Instead of 1 SQL INSERT per vote, it emits 1 multi-row sql/insert-batch! when 200 ballots accumulate. Tally snapshots are taken OFF the hot path, cutting statement count by an additional 52%.

★ Compression Gain: 200:1 raw ballot compression, ~20x to 40x aggregate DB statement reduction.
